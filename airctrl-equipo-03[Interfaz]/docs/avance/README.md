# Documentacion del primer avance

Esta carpeta reune el analisis, el diseno y las decisiones tomadas durante el primer avance del proyecto final.

## Contenido

1. `analisis.md`: problema, alcance y usuarios del sistema.
2. `diseno.md`: capas, entidades, relaciones y flujo implementado.
3. `decisiones-tecnicas.md`: estructuras de datos seleccionadas y su justificacion.
4. `datos.md`: archivos CSV, campos, relaciones y validaciones.
5. `requisitos-reglas.md`: requisitos funcionales, reglas de negocio y casos limite.
6. `entrega.md`: componentes integrados, ejecucion y pruebas del avance.

El sistema fue desarrollado en Java y utiliza los archivos proporcionados para la actividad .
