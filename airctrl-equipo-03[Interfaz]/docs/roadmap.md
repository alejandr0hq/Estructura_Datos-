# Roadmap del proyecto

El proyecto se desarrolla por fases. Cada fase construye sobre la anterior y responde a una necesidad concreta del problema: **no es una lista de tareas sueltas, es una evolución del mismo sistema**.

| Fase | Nombre | Qué se espera |
|---|---|---|
| 1 | Modelo de operaciones | Entidades de vuelos, aeronaves, puertas y equipaje; carga de CSV |
| 2 | Gestión de vuelos | Registro, consulta y búsqueda del itinerario |
| 3 | Procesamiento de operaciones | Atender pendientes, actualizar estados, respetar reglas |
| 4 | Priorización | El sistema siempre propone atender primero lo más urgente |
| 5 | Búsqueda eficiente | Consultas por id, aerolínea o estado sin recorrer todo cada vez |
| 6 | Organización jerárquica | Estructuras que representen terminales, puertas y zonas |
| 7 | Ordenamiento y consultas | Reportes ordenados por criterios operativos |
| 8 | Análisis de conexiones | Recorridos sobre el mapa interno del aeropuerto |
| 9 | Optimización y pruebas | Suite completa, medición y justificación de decisiones |

## Notas

- Las fechas y el alcance exacto de cada fase los define el profesor durante el semestre.
- En cada entrega se evalúan: funcionamiento, pruebas, y **justificación técnica** de las decisiones tomadas.
- Ninguna fase indica qué herramienta usar para organizar tus datos: elegirlo y defenderlo es parte del aprendizaje.
